# `ht_atom_full_outputs`

**Severity:** ERROR
**Scope:** modules under `modules/*/atoms/` (atom tier)

## Summary

Enforces that an atom exposes every provider-exported attribute of its wrapped resource as an output. Molecules and consumers must never need to reach around an atom or re-derive data that the provider already exports.

The expected output set (including computed-only attributes like `id`) is read from a static attribute table (`resource_schemas.go`) generated by `scripts/scaffold-atom.py`.

## Rule checks

| Check | Trigger | Message |
|-------|---------|---------|
| Missing output | expected output not defined in module | `atom is missing output "X" (required by resource schema for Y)` |

## Notes

- If the resource type is not in the attribute table, the rule is silently skipped.
- A single `value = resource.this` output was explicitly rejected: one sensitive attribute would poison the whole output, terraform-docs would document nothing, and consumers would couple to raw schema paths.
