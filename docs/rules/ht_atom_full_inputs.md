# `ht_atom_full_inputs`

**Severity:** ERROR
**Scope:** modules under `modules/*/atoms/` (atom tier)

## Summary

Enforces that an atom exposes every configurable attribute of its wrapped resource as an input variable. A partial atom is a broken atom — callers have no way to configure attributes that are absent.

The expected variable set is read from a static attribute table (`resource_schemas.go`) generated by `scripts/scaffold-atom.py` in `ht-terraform-modules`. Deprecated provider attributes are excluded from the table.

## Rule checks

| Check | Trigger | Message |
|-------|---------|---------|
| Missing variable | expected variable not defined in module | `atom is missing variable "X" (required by resource schema for Y)` |

## Notes

- If the resource type is not in the attribute table, the rule is silently skipped. Add new resources by running `scripts/scaffold-atom.py --update-schema-table`.
- Nested blocks (e.g. `versioning_configuration`) are represented as a single typed `object(...)` variable, not as individual variables per nested attribute.
